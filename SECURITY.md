# Security and privacy

Do not report patient information through a public GitHub issue. Contact the
corresponding author or institutional study contact through an approved private
channel. Public artifacts must exclude direct identifiers, quasi-identifiers
that enable re-identification, credentials, private endpoints, database dumps,
and document/image metadata.

This repository is research software and not a clinical service. Suspected
unsafe clinical output should be handled under the study's institutional
incident-review process, not treated as a software-only defect.
