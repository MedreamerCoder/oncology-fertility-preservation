# Run and corpus metadata

Replace the empty CSV templates in this directory with the exact study records.
Do not put credentials, internal endpoints, patient identifiers, or copyrighted
full text in these files.

- `model_runs.csv` records one immutable row per model run.
- `knowledge_base_manifest.csv` records provenance without redistributing source
  content. Include all 315 guidelines/consensus documents and six books reported
  in the manuscript, subject to author verification.
