# Generated analysis outputs

This directory is reserved for locally generated reproducibility outputs from the commands documented in the top-level README and `docs/REPRODUCIBILITY.md`.

Generated CSV/JSON result files are ignored by Git by default so that source artifacts remain separate from derived outputs. For an archival manuscript release, regenerate the analyses in a clean environment, compare all outputs with the reported manuscript statistics, and publish the approved result bundle as a tagged release or archived artifact with version/checksum information.
