# Knowledge-base provenance

This directory documents the frozen knowledge base used by the study without redistributing copyrighted source texts.

`manifest.csv` should contain one row per guideline, consensus document, article/book source, or other knowledge-base item. For each source, record enough provenance to allow an independent auditor to identify the exact version used, including title, issuing organization or authorship, version/publication date, URL or DOI, language, checksum where applicable, acquisition date, inclusion reason, and redistribution status.

The manuscript reports a curated bilingual corpus comprising 315 guidelines or consensus documents and six authoritative books. Populate the manifest only from the actual frozen study corpus. Do not infer or reconstruct missing entries from the manuscript bibliography.

If graph schema, Neo4j constraints, or de-identified graph-import scripts are released, place them in this directory or under `scripts/` and document their relationship to the frozen corpus.
